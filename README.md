Autokey-gtk and qt didnt work for a reason and im waiting for the software to be updated/fix or for someone to find a workaround, i made this script to do macros on roblox, i named the file spam z because i use the z move for macro-ing(i dont know if this is the right term or not). 
# Caution
Before using the script make sure you check what the code looks like or do (well, it spams z) we never know when to be more cautious about something we use or do in the internet.
# How To Use
Download the python script and open your desired terminal, then cd into the directory where your download go

```Example : home/your_user/Downloads/spam z.py```
Then run
``` python spam.z.py```
or
```python3 spam.z.py```
Depends on your system configuration
